# Политика хранения и передачи данных

## Принцип

Релиз должен быть автономно проверяемым и одновременно не нарушать ограничения правообладателей.

Для каждого зарегистрированного snapshot используется один из двух режимов:

1. **`include`** — raw-файл включается в поставку и проверяется по SHA-256;
2. **`exclude_raw_keep_derived`** — raw-файл не распространяется, но поставка содержит:
   - точный экспорт использованных строк;
   - официальный URL загрузки;
   - ожидаемый SHA-256 исходного snapshot;
   - дату получения, content type и размер;
   - детерминированный download recipe.

Наличие derived export не означает право на повторное распространение исходного файла.

## Требования к источнику

Для каждого источника фиксируются:

- owner;
- terms URL;
- access mode;
- допустимость хранения;
- допустимость преобразования;
- решение о включении raw в архив;
- обязательная атрибуция;
- дата принятия внутренней консервативной политики поставки.

Дополнительное внешнее юридическое заключение не является программным release blocker. Проект применяет консервативный режим: при отсутствии однозначного разрешения raw исключается, а передаются derived rows и download recipe.
