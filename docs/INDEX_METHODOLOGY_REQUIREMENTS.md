# Требования к методологии индексных модулей

## Основные названия в русской версии

- `HDI` → `ИЧР — Индекс человеческого развития`;
- `HCI` → `Индекс человеческого капитала Всемирного банка — историческая редакция 2020`;
- `GTCI` → `Индекс глобальной конкурентоспособности талантов`;
- `GII` → `Глобальный инновационный индекс`;
- `IDI` → `Индекс развития ИКТ`;
- `QS_ET` → `QS: инженерия и технологии — страновая агрегация платформы`;
- `HTEI` → `Индекс занятости в высокотехнологичных отраслях`.

## Обязательное разграничение статусов

Платформа должна различать:

1. официальный итоговый score;
2. официальный score с аналитической диагностической декомпозицией платформы;
3. историческую официальную редакцию;
4. авторскую страновую агрегацию официального университетского рейтинга;
5. авторский составной индекс проекта;
6. экспериментальную аналитическую модель, ожидающую внешней валидации.

## Формулы и пояснения

Каждая индексная страница раскрывает официальный источник, фактический год, методику, компоненты, нормировку, веса только там, где они действительно являются частью используемой формулы, и статус пересчёта.

- HDI: официальный score UNDP; официальная формула — геометрическое среднее health, education и income indices. Min-max diagnostics платформы не называются официальным пересчётом.
- HCI: официальный исторический score 2020 до загрузки официального HCI+ 2026.
- GTCI: официальный итоговый score и официальные pillar ranks; преобразованная шкала — диагностика платформы.
- GII: официальный score и pillar scores; платформа не пересчитывает GII равными весами.
- IDI: официальный индекс ITU.
- QS_ET: воспроизводимая авторская страновая агрегация institution rows; не официальный QS country ranking.
- HTEI: авторская формула scientific v5, подробно описанная в `HTEI_METHODOLOGY_V5.md`.

## HTEI v6

```text
HTEI substantive score = Σ(normalized component score × effective component weight)
```

Эффективные веса перенормируются по доступным компонентам только после прохождения правил допуска выбранного режима. Data confidence публикуется отдельно и не умножается на score.

## QS country aggregation

Должны быть раскрыты:

- количество ранжированных вузов;
- лучший ранг;
- top-100 / top-250 / top-500;
- median и mean rank;
- rank-band points и вклад каждого вуза;
- годы и institution-level source rows.
