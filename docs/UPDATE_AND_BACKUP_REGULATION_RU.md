# Регламент обновления и резервного копирования

## Периодичность

- World Bank HCI+ — после выхода новой редакции;
- HDI, GII, GTCI, IDI, QS — по официальному выпуску;
- ILOSTAT, OECD, Eurostat, UIS — ежеквартальная проверка;
- национальная статистика — ежеквартально;
- корпоративная отчётность — после годовых отчётов и 10-K/20-F.

## Последовательность

1. Создать backup БД.
2. Скачать официальный raw-файл без перезаписи прошлого snapshot.
3. Проверить host, content type, размер и SHA-256.
4. Запустить transformation.
5. Пересчитать зависимые показатели.
6. Выполнить валидаторы и тесты.
7. Сформировать source matrix и release evidence.
8. Выполнить Playwright и сохранить evidence.

## Восстановление

При провале любого gate восстановить последний backup, сохранить failed operational run и не публиковать частично обновлённую БД.
