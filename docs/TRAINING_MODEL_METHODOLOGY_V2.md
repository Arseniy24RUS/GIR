# Модель оценки конкурентоспособности национальных систем подготовки кадров для высокотехнологичных отраслей

## Назначение

Модель реализует пункт 2.3 и результат 3.3.1 исходного ТЗ. Она не является вторым авторским индексом HTEI и не подменяет официальные международные рейтинги. Это отдельный аналитический инструмент, объединяющий четыре блока, дословно названные заказчиком:

1. институциональная среда — 25%;
2. образовательная инфраструктура — 30%;
3. корпоративные стратегии — 25%;
4. международное сотрудничество — 20%.

## Расчёт

Каждый блок строится из воспроизводимых компонентных показателей международных индексов и HTEI. Для доступных компонентов рассчитывается нормированный балл. При пропусках вес нормируется только в пределах доступного набора; профиль допускается при наличии не менее трёх блоков и 70% суммарного веса. Фактический год и источник сохраняются для каждого компонента.

## Ограничения

- официальные международные индексы используются как источники и не пересчитываются платформой;
- корпоративные стратегии представлены прямыми числовыми показателями только при наличии официальной отчётности; прокси маркируются;
- разные блоки могут иметь разные фактические годы данных;
- итоговое место не должно интерпретироваться без профиля свежести и качества.

## Валидация

Контур `giip/scientific_release.py` выполняет:

- 200 детерминированных вариаций весов ±20%;
- сценарий равных весов;
- коэффициент Спирмена между базовым и альтернативными рейтингами;
- среднее и максимальное изменение места;
- аудит фактических лет данных.

Результат сохраняется в `outputs/scientific_validation_report.json` и таблице `methodology_audit_runs`.
