# Приёмочное досье по исходному ТЗ МГИМО—ФНИСЦ РАН

Досье воспроизводит ровно четыре обязательные пары ТЗ.

## 2.1 → 3.1.2

**Создание интегрированной базы данных по трудовым ресурсам в высокотехнологичных отраслях** на основе агрегации данных международных организаций, национальных статистических служб, корпоративной отчётности и специализированных рейтингов.

Доказательства: `source_registry`, `raw_snapshots`, `source_observations`, `national_statistics_metrics`, `corporate_metrics`, source matrix, provenance API.

## 2.2 → 3.2.1

**Формирование системы индикаторов для мониторинга развития технологических кадров, включая Индекс занятости в высокотехнологичных отраслях (High-tech employment index).**

Доказательства: HTEI v6, формула, четыре режима публикации, компоненты, статистический аудит, API и UI.

## 2.3 → 3.3.1

**Разработка модели оценки конкурентоспособности национальных систем подготовки кадров для высокотехнологичных отраслей** на основе институциональной среды, образовательной инфраструктуры, корпоративных стратегий и международного сотрудничества.

Доказательства: `training_model_scores`, `training_model_components`, методологический паспорт, sensitivity audit.

## 2.4 → 3.4.1

**Подготовка практических рекомендаций по формированию трудовых ресурсов в высокотехнологичных отраслях Российской Федерации.**

Доказательства: восемь структурированных мер, policy brief API, русская и английская версии.

## Финальная проверка

```bash
python scripts/validate_release_readiness.py --strict
```

Приёмочный статус считается окончательным только при `customer_final_release` и отсутствии blockers.
