# HCI+ 2026 и исторический HCI: правило представления

## Основной актуальный модуль

В релизной версии основным модулем человеческого капитала является официальный **Human Capital Index Plus (HCI+) 2026** Всемирного банка. Официальная шкала — 0–325. Индекс включает три направления:

- здоровье;
- образование;
- занятость.

Загрузка выполняется только из официальных страновых briefs Всемирного банка скриптом:

```bash
python scripts/fetch_hci_plus_2026.py
```

Релизный порог — не менее 150 официальных страновых значений.

## Исторический HCI

Исторический Human Capital Index сохраняется в базе и используется для ретроспективной части графика до 2020 года. HCI и HCI+ основаны на разных методологических редакциях и **не образуют один официальный непрерывный временной ряд**.

На комбинированном графике:

- исторический HCI — синяя пунктирная линия и круглые маркеры;
- HCI+ 2026 — зелёный ромб;
- между редакциями показывается предупреждение о методологическом разрыве.

Для визуальной совместимости исторический HCI может отображаться на оси 0–325 через техническое масштабирование `HCI × 3,25`. Это **не официальный пересчёт** и не применяется в базе, рейтинге или API как новое значение.

## Provenance

Для каждой страны сохраняются:

- официальный PDF brief;
- URL;
- SHA-256;
- дата получения;
- официальный итоговый score;
- баллы трёх направлений;
- raw snapshot и transformation run.
