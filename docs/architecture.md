# Архитектура GIR — Глобальный рейтинг индексов

GIR — Глобальный рейтинг индексов (GIR — Global Index Ranker) строится как вычислительный контур международных индексов:

Технический namespace `giip`, `GIIP_DB`, CLI `python -m giip.cli` и существующие пути базы данных сохранены для обратной совместимости; публичный бренд продукта — GIR.

`official sources → raw snapshots → normalized facts → index engine → component diagnostics → recommendation engine → dashboard/API`.

Главная вкладка показывает страновой профиль по 7 индексам. Остальные вкладки посвящены каждому индексу: карта, рейтинг стран, компоненты, вклад факторов и диагностический приоритет.

## Почему HTEI

В исходном ТЗ требуется именно High-tech employment index. Поэтому в новой версии оставлен один авторский индекс — HTEI. Он показывает, насколько человеческий капитал страны превращается в занятость, профессии, R&D-персонал, STEM pipeline и спрос на high-tech навыки.

## QS Engineering & Technology

QS Engineering & Technology не является страновым индексом. В GIR он представлен как derived country aggregation: сила страны в инженерно-технологическом университетском сегменте рассчитывается через наличие вузов в рейтинге, позиции вузов, репутацию и исследовательские показатели. Для промышленного релиза нужна юридически корректная политика использования данных QS.
