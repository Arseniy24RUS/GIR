# Индекс занятости в высокотехнологичных отраслях — методология HTEI v6

## 1. Назначение

Индекс занятости в высокотехнологичных отраслях (High-tech Employment Index, HTEI) является авторским составным показателем проекта. Он реализует формулировку исходного ТЗ: **«Формирование системы индикаторов для мониторинга развития технологических кадров, включая Индекс занятости в высокотехнологичных отраслях (High-tech employment index)»**.

HTEI не является официальным индексом международной организации. Весовая схема и состав показателей приняты в утверждённом отчёте по НИР. Версия v6 не пересматривает это утверждённое решение, а повышает сопоставимость, воспроизводимость и прозрачность расчёта.

## 2. Режимы публикации

### 2.1. Direct Core

Страны, для которых трудовые компоненты основаны на прямых high-tech/KIS, HRST либо официальных национальных статистических рядах. Используется для наиболее строгой интерпретации.

### 2.2. Common Support

Основной международный рейтинг. Все страны рассчитываются по одному и тому же фиксированному набору четырёх компонентов:

1. доля занятости в высокотехнологичных секторах либо гармонизированный отраслевой proxy;
2. профессиональная структура технологических кадров либо гармонизированный occupational proxy;
3. STEM pipeline;
4. технологические результаты.

У каждой страны одинаковая формула и одинаковая компонентная сигнатура. Исходные утверждённые веса перенормируются только внутри этого фиксированного набора.

### 2.3. Proxy Extended

Расширенное сопоставимое пространство. Допускает шесть утверждённых компонентов при достаточном покрытии, но явно маркирует широкие прокси. Применяется для policy benchmarking, а не как замена Common Support.

### 2.4. ASOF Diagnostic

Диагностический профиль по последним доступным официальным наблюдениям. Компоненты могут относиться к разным годам. **Место не присваивается.** Режим предназначен для содержательной диагностики стран с неполными или несинхронными рядами.

## 3. Компоненты и утверждённые веса

| Код | Русское название | Вес |
|---|---|---:|
| `HT_EMPLOYMENT_SHARE` | занятость в high-tech/KIS либо гармонизированный отраслевой proxy | 0,22 |
| `HIGH_TECH_OCCUPATIONS` | технологические/STEM-профессии либо широкий профессиональный proxy | 0,18 |
| `RD_PERSONNEL` | персонал исследований и разработок | 0,18 |
| `STEM_PIPELINE` | поток подготовки STEM-кадров | 0,16 |
| `TECH_OUTPUTS` | технологические результаты | 0,14 |
| `CORPORATE_STRATEGY` | корпоративная технологическая активность, не прямой показатель вакансий | 0,12 |

## 4. Формула

Для профиля с набором компонентов \(S\):

\[
HTEI_c = \sum_{i \in S} \tilde w_i z_{ic},
\qquad
\tilde w_i = \frac{w_i}{\sum_{j \in S} w_j}.
\]

В Common Support набор \(S\) одинаков для всех стран. В ASOF диагностике формула используется только для профиля и не порождает международный ранг.

## 5. Качество данных

Качество данных **не умножается на содержательную оценку** и не меняет место страны. Публикуются отдельно:

- `substantive_score`;
- `confidence_score`;
- `coverage_class`;
- `freshness_class`;
- фактические годы компонентов;
- количество независимых групп источников;
- интервалы score и rank.

## 6. Выбор наблюдений

При выборе официального наблюдения применяются последовательно:

1. методическая сопоставимость показателя;
2. фактический год данных;
3. качество и полнота метаданных;
4. приоритет источника только как разрешение равенства.

Старое наблюдение более предпочтительного источника не должно вытеснять существенно более свежий официальный ряд без зафиксированного методического основания.

## 7. Прямые показатели и прокси

Каждый компонент содержит `proxy_status`, `indicator_code`, `source_group`, `selection_rule`, фактический год и интерпретацию.

- Eurostat high-tech/KIS и HRST считаются прямыми рядами для соответствующего охвата.
- ILOSTAT ISIC J+M является широким отраслевым proxy и не называется безусловно high-tech employment.
- ISCO-08 major groups 2–3 являются широким профессиональным proxy, включающим не только STEM/high-tech профессии.
- BERD/GERD характеризует корпоративное участие в НИОКР и не подменяет статистику вакансий.

## 8. Внутренняя проверка устойчивости

Платформа выполняет не менее 200 расчётных прогонов:

- вариации весов;
- альтернативные нормировки;
- leave-one-component-out;
- корреляционный анализ;
- missingness-pattern audit;
- интервалы score и rank.

Весовая схема не требует повторного утверждения, поскольку закреплена утверждённым отчётом по НИР. Внутренний аудит проверяет воспроизводимость и устойчивость результата.

## 9. Ограничения интерпретации

1. HTEI измеряет сравнительную конфигурацию технологических кадров, а не прямой причинный эффект государственной политики.
2. Proxy Extended нельзя интерпретировать как более строгий рейтинг, чем Common Support.
3. ASOF-профили не следует ранжировать.
4. Небольшие различия score внутри интервалов неопределённости не считаются содержательно значимыми.
5. Результаты должны использоваться вместе с компонентами, источниками и фактическими годами.
